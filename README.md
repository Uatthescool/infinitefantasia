# Infinite Fantasia

The website for **Infinite Fantasia**, a story-driven tactical roguelite where you build a new class each run by fusing small fantasy jobs. It's an early prototype for testers.

**Play it:** https://uatthescool.github.io/infinitefantasia/

This repository holds only the built website: the home page and the browser build of the game (`play/`). The game's development happens elsewhere.
